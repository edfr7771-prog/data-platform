# متطلبات النشر داخل المملكة

> لا نشر عام قبل: اختيار مزوّد الاستضافة، وربط SMTP ومزوّد SMS، واعتماد الكتابة اللاتينية الرسمية والنطاق. ولا يُغيَّر DNS تلقائيًا.

## الاستضافة
تفيد نتيجة بحثنا السابقة (مراجعة 20 سبتمبر 2026 على مصادر الجهة) أن المادة الثامنة من لائحة الهيئة العامة للعقار تشترط استضافة خادم المنصة داخل المملكة. **هذه قراءة لا استشارة قانونية**، ويُطلب توضيح كتابي من الهيئة. خيارات مدروسة سابقًا: Oracle (جدة) وWafaTech، وتُراجَع الأسعار والتوفر عند القرار. بنية Arm تحتاج اختبارًا قبل الاعتماد (لم تُجرَّب هنا).

## المكوّنات
| المكوّن | المتطلب |
|---|---|
| التطبيق | Node.js 22، `next start` خلف Nginx، خدمة systemd بمستخدم غير جذري |
| PostgreSQL | 16، مستخدم بصلاحيات محدودة على قاعدة التطبيق، اتصال محلي أو شبكة خاصة |
| التخزين | لا ملفات مرفوعة تُحفظ الآن (الاستيراد في القاعدة). عند إضافة مرفقات: تخزين داخل المملكة بإذن 640 |
| SSL | شهادة (Let's Encrypt) على النطاق الرسمي، وتحويل http وwww إلى الرابط الرسمي مع المسار والمعلمات |
| النسخ الاحتياطي | `pg_dump` يومي مشفَّر إلى وجهة **داخل المملكة** خارج الخادم، مع اختبار استعادة دوري |
| المراقبة | `/api/health` (قاعدة، APP_URL، حالة تسليم البريد/الرسائل) + سجلات الخادم بلا بيانات شخصية |
| الأسرار | ملف بيئة واحد على الخادم بإذن 640، لا يُرفع إلى Git ولا يُكتب في محادثة |
| النطاق | `APP_URL` من البيئة؛ لا نطاق ثابت في الكود |

## متغيرات البيئة
انظر `.env.example`. الإلزامي للإنتاج: `DATABASE_URL`, `APP_URL` (https), `APP_SECRET` (32+), `OTP_EMAIL_DELIVERY=smtp` + `SMTP_*`, `OTP_SMS_DELIVERY=webhook` + `SMS_WEBHOOK_URL/TOKEN`, و`OTP_DEV_SHOW=false`. بلا SMTP وSMS مضبوطين يُغلق التسجيل صراحةً (`registration_open=false`).

## أول مدير للمنصة
بلا أي استثناء من التوثيق: يُسجَّل الحساب بالمسار العادي (يلزم SMTP وSMS)، ويُرقّى تلقائيًا إن كان بريده في `ADMIN_IDENTIFIERS`. لا يوجد طريق بديل.

## عند تعدد نسخ التشغيل
محدّد المعدل العام في الذاكرة يلزمه مخزن مشترك (Redis أو جدول)، وإلا ضُرب حدّه بعدد النسخ.

## الفصل بين الخدمات
التطبيق والقاعدة والتخزين والبريد والرسائل والخرائط ومزوّد الذكاء الاصطناعي تُضبط كلها بالإعدادات والمحوّلات، فتنتقل أي منها دون تعديل المنطق. **لا تنتقل بيانات عملاء خارج البيئة المختارة دون سياسة معتمدة.**
