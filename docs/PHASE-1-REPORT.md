## 3) ما اكتُشف وأُصلح أثناء البناء (يُظهر عمق الفحص)
1. **اعتماديات:** `nodemailer` 7.x فيه ثغرات عالية (حقن أوامر SMTP وCRLF) ← 10.0.13؛ و`csv-parse` فيه تنبيه متوسط ← 7.0.3.
2. **خلل تصميم CSRF لم يلتقطه أي اختبار آلي:** حمايتي كانت تشترط رأس `Origin`، والمتصفح الحقيقي لا يرسله لطلبات الصفحة نفسها، فكانت ترفض كل مستخدم شرعي. اكتُشف حين شغّلتُ معالج الاستيراد في متصفح فعلي. أُصلح بالاعتماد على `Sec-Fetch-Site` ثم `Origin` ثم `Referer`، وأُضيفت 6 فحوص.
3. **فيض أفقي على الجوال** (+332px) في صفحة العقارات: نص مخفي بصريًا (`sr-only`) بموضع مطلق خارج حاوية الجدول. أُصلح بحاوية `position:relative`.
4. **خصوصية الزائر:** كنتُ أحمّل الخطوط من Google (يكشف عنوان كل زائر لطرف ثالث) ← استُضيفت ذاتيًا.
5. **عرض رقم مالي بشكل مضلّل:** «+4.2%» كان يظهر «4.2%+» بسبب اتجاه النص ← عُزل اتجاه الأرقام.
6. **أخطاء في اختباراتي أنا** صُحّحت قبل أن تضلّلني: توقعات تصنيف الصفوف، واقتباس CSV، وحصة إرسال مستهلَكة، وعلامة BOM التي يُزيلها `fetch` (تحققتُ من البايتات الخام).

## 4) ما لم يُبنَ (صراحةً)
- استيراد Excel (xlsx).
- الواجهة الإنجليزية LTR (الاتجاه العربي أولًا، والإنجليزية في الخطة)، وPWA (manifest وأيقونات).
- تعديل عقار من الواجهة (API التعديل موجود) ومرشّحات الجدول من الواجهة (API يدعمها).
- دعوة أعضاء المؤسسة وتغيير أدوارهم من المنتج: الأدوار غير `org_admin` تُسند حاليًا من القاعدة فقط. **ثغرة وظيفية مهمة لـ RBAC**، وأقترحها أول عمل في المرحلة الثانية.
- تصدير/حذف بيانات الحساب، ومهمة تنظيف رموز التحقق، ومحدّد معدل مشترك، ورأس CSP.
- المراحل 2 إلى 4: التحليلات والأحياء والخرائط، والمطابقة وCRM ومستشار الذكاء الاصطناعي وبوابة خصوصيته، والتقارير والمؤشر والأكاديمية والباقات ولوحة الإدارة.
- اختبارات المتصفح (Puppeteer) شُغّلت بأدوات خارجية ولم تُضمَّن في المستودع بعد (تُدمج مع CI).

## 5) ما يحتاج خدمة أو قرارًا خارجيًا
| البند | الحالة |
|---|---|
| استضافة داخل المملكة | غير موجودة (قرارك مؤجل) |
| SMTP للبريد | غير مربوط، **لم يُختبر أمام مزوّد حقيقي** |
| مزوّد SMS | غير محدد؛ **التسجيل مغلق صراحةً** حتى يُربط البريد وSMS (`registration_open=false`) |
| النطاق | `APP_URL` من البيئة؛ لا نطاق ثابت |
| مزوّد خرائط / مزوّد ذكاء اصطناعي | للمراحل التالية |

## 6) قرارات تنتظرك
1. **الكتابة اللاتينية الرسمية:** TAMALAAN أم tamaalann (هويتك المعتمدة) قبل أي نطاق أو حساب أو اسم حزمة.
2. هل تريد **Excel** في المرحلة الأولى المكمِّلة؟ (يحتاج اختيار مكتبة آمنة).
3. **دعوة أعضاء المؤسسة** وتغيير الأدوار: أبدأ بها الآن؟ وهل مؤسسة واحدة لكل مستخدم كافية؟
4. اعتماد البدء بـ **المرحلة الثانية** (التحليلات وسعر المتر والوسيط والأحياء).
5. **مراجعة قانونية** لنظام حماية البيانات الشخصية ومتطلبات الهيئة قبل أي بيانات حقيقية.

## 7) كيف تتحقق بنفسك
```bash
npm ci && npm audit && npm run typecheck && npm run test:unit
cp .env.example .env   # DATABASE_URL وAPP_SECRET وOTP_DEV_SHOW=true (محليًا) وADMIN_IDENTIFIERS=admin@test.local
npm run migrate && npm run build && npm start
# في نافذة أخرى، على قاعدة فارغة:
DATABASE_URL=... TEST_APP_URL=http://localhost:3000 npm run test:integration
```
افتح `http://localhost:3000/register`، وسجّل بأي بريد وجوال: الرموز تظهر على الصفحة محليًا فقط.
